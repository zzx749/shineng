# 失能评估辅助系统 · 前端对接清单

> 面向前端同学。本文是「切真实接口」的操作清单，接口细节以 [api-docs.md](api-docs.md) 为唯一依据。
> 后端已通过回归测试（44/44），可直接联调。

---

## 一、快速开始（先跑通后端）

- [ ] 环境：**Node ≥ 22.5**（后端用 `node:sqlite`，低版本起不来）
- [ ] 启动后端：`cd elder-eval-backend && npm install && node app.js`
- [ ] 确认服务地址：`http://localhost:3000/api`
- [ ] 登录账号：管理员 `admin / admin123`；评估员走注册接口

---

## 二、切真实接口（核心两处）

- [ ] `src/api/http.js`：`USE_MOCK` 改为 `false`
- [ ] `baseURL` 指向 `/api`（或 vite 代理转发到 `http://localhost:3000`）

---

## 三、字段对齐（务必逐条核对）

- [ ] 外层字段全部 **snake_case**：`created_at`、`updated_at`、`id_card`、`children_phone`、`elder_id`、`assessor_id`、`correction_note`、`dimension_levels`、`computed_level`、`manual_level`
- [ ] 主键 `id` 是**数字**（自增），不是字符串
- [ ] `scores` 内 5 个 key **保留 camelCase**：`lifeAbility`、`workAbility`、`timeOrientation`、`personOrientation`、`socialContact`（其余 17 个是单词小写）
- [ ] 时间戳为**毫秒数**（如 `1720000000000`），不是 ISO 字符串

---

## 四、枚举映射

| 字段 | 取值 | 前端展示 |
| --- | --- | --- |
| `gender` | `MALE` / `FEMALE` | 男 / 女 |
| `role` | `admin` / `staff` | 管理员 / 评估员 |
| `corrected` | `true` / `false` | 是否发生过纠正 |

---

## 五、业务规则（后端强制）

- [ ] 新增评估**不要传** `assessor` / `assessor_id`，后端根据 token 自动写入（快照，改姓名不影响历史记录）
- [ ] 纠正：`manual_level ≠ computed_level` 时**必须传** `correction_note`，否则 400
- [ ] `date` 不传时后端默认取当天，前端可不传
- [ ] 取值校验（传错返回 400，无需前端兜底）：
  - `scores` key 限 22 项、取值 `0/1/2`
  - `computed_level` / `manual_level` 取值 `0~3`
  - `gender` 取值 `MALE` / `FEMALE`
- [ ] 所有删除为**软删除**，前端无需区分，表现为列表/详情不再出现

---

## 六、鉴权与错误处理

- [ ] 除登录/注册外，所有请求带 `Authorization: Bearer <token>`
- [ ] token 有效期 **7 天**，过期接口返回 401
- [ ] 失败统一读 `message` 字段

| 状态码 | 含义 | 前端处理 |
| --- | --- | --- |
| 200 / 201 | 成功 | 正常处理 |
| 400 | 参数/校验失败 | 弹 `message` |
| 401 | 未登录 / token 失效 / 账号删除 | 清登录态，跳登录页 |
| 403 | 无权限 | 提示无权限 |
| 404 | 资源不存在或已删除 | 提示不存在/已删除 |
| 500 | 服务器错误 | 提示系统异常 |

---

## 七、职责边界

- **前端算**：`scores` 22 项、`dimension_levels` 四维、`computed_level` 系统等级（`src/constants/scoring.js`）
- **后端存 + 校验**：落库、取值校验、自动填 `assessor` 快照、纠正留痕

---

## 八、开放项（不阻塞对接，需后续确认）

- [ ] **评分阈值**：`scoring.js` 的「维度总分 → 等级」阈值为占位近似值，需专业老师最终确认
- [ ] **无分页**：列表全量返回 `{ list, total }`，数据量大后再加 page/pageSize
